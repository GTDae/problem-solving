# Problem Solving — FizzBuzz

The Odin Project, Foundations, [Problem Solving](https://www.theodinproject.com/lessons/foundations-problem-solving) lesson.

Built the classic FizzBuzz example using the lesson's own three-step process:
1. **Understand** the problem
2. **Plan** — inputs, outputs, pseudocode
3. **Divide and conquer** — break it into subproblems, solve smallest first

Each subproblem is its own commit, in order, so the history shows the actual build-up rather than one finished file dropped in at the end.
